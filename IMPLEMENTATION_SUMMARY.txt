HOW TO SET UP AND RUN
================================================================================

1. DATABASE SETUP:
   a) Open MySQL command line
   b) Run: mysql -u root -p < database/setup.sql
   c) Or import setup.sql in MySQL Workbench

2. VERIFY DATABASE CONNECTION:
   a) Edit: src/main/java/com/bookstore/util/DBConnection.java
   b) Update: USER, PASSWORD if different from defaults (root, empty)
   c) Ensure MySQL is running on localhost:3306

3. DEPLOY TO TOMCAT:
   a) Build project (Maven or IDE)
   b) Deploy WAR or exploded folder to Tomcat webapps
   c) Start Tomcat

4. TEST HOMEPAGE:
   a) Visit: http://localhost:8080/WebBanSach/
   b) Should see homepage with categories and products
   c) Carousels should work (left/right buttons)

================================================================================
KEY TECHNICAL DETAILS
================================================================================

Session Management:
  - User: session.getAttribute("user")
  - Cart: session.getAttribute("cart") as List<CartItem>

Data Flow:
  - Browser → Servlet → DAO → MySQL → DAO → JSP → Browser

Database Credentials (default):
  - Host: localhost
  - Port: 3306
  - Database: bookstore
  - User: root
  - Password: (empty)

JSP Tags Used:
  - <%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
  - <%@ taglib prefix="fmt" uri="http://java.sun.com/jsp/jstl/fmt" %>

Resource Paths in JSP:
  - Use: ${pageContext.request.contextPath}/path/to/resource
  - Example: <img src="${pageContext.request.contextPath}/css/main.css">
